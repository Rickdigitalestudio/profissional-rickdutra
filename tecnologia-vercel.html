Vercel
Site no ar em minutos

Intermediário · 65%

Aprendi a sair do “só no meu PC” para link público com HTTPS: conecto o GitHub na Vercel e cada push vira deploy automático com preview para o cliente aprovar antes de ir ao ar.

Clique em cada passo

1 · Conectar o GitHub

Importo o repositório na Vercel em 2 cliques. Nada de FTP ou painel confuso.

2 · Deploy automático

Cada git push gera um build. Se der erro, a Vercel mostra o log exato.

3 · Link de preview

Cada commit ganha URL temporária — mando para o cliente aprovar no celular.

4 · Domínio + HTTPS

Aponto seu domínio (ex.: suasite.com.br) e o certificado sai grátis.

0 de 4 passos explorados

O que aprendi

  • Deploy contínuo ligado ao GitHub
  • Preview URL por commit/branch
  • Variáveis de ambiente básicas
  • Domínio próprio + HTTPS grátis
  • Rollback para versão anterior em 1 clique

O que consigo fazer

  • Colocar seu site no ar com link profissional
  • Atualizações sem downtime (push = no ar)
  • Página de preview para aprovação
  • Ligar GitHub Pages ou Vercel ao domínio
  • Escolher hospedagem certa p/ cada projeto
